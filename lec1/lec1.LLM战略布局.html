01 · Paradigm Shift

行业主线：能力竞争正在从“生成”转向“完成任务”

2023
Chatbot

单轮问答、知识覆盖、指令遵循。核心指标是“回答得像不像一个聪明人”。

2024
Reasoning + Multimodal

复杂推理、图像视频理解、长上下文。模型开始“看得多、想得深”。

2025
Coding Agent

代码、终端、测试和仓库提供了第一套规模化、可验证的 Agent 环境。

2026 →
Long-horizon Agent

持续数小时或数天工作；规划、调用工具、观察反馈、回滚、重试并交付结果。

长文本、多模态、推理、工具调用并非四条独立赛道；它们正在汇合为 Long-horizon Agent 的底层能力。
判断：Coding Agent 是第一个 PMF，但不是最终终局Sources: OpenAI · Anthropic · Google DeepMind
02 · The Real Stack

大厂竞争不是单一模型竞争，而是五层系统竞争

① Foundation Model
Dense / MoE、推理、代码、原生多模态、长上下文
“脑子”
② Post-training
Reasoning RL、Tool-use SFT、Agentic RL、Long-horizon training
“如何学会工作”
③ Agent Harness
工具注册、状态管理、context compaction、memory、sub-agent、权限
“操作系统”
④ Environment
代码仓库、浏览器、桌面、企业流程、实验室、仿真器
“可行动的世界”
⑤ Distribution
Chat、IDE、Search、Office、手机、社交、云与企业数据
“真实反馈闭环”
长上下文 ≠ 长任务

能放入 1M token，不等于能维持目标、处理失败、跨窗口恢复并控制成本。

多模态正在被 Agent 吞并

终局不是“会看图”，而是 perception → reasoning → action → new observation。

Harness 正在成为核心差异

前沿性能越来越取决于模型、系统提示、工具、上下文管理与执行循环的联合优化。

战略含义：不要只建设模型团队，还要建设环境、评测和 Agent 系统团队

08 · Take-away

给 LLM 技术负责人的五个结论

下一轮竞争不是
“谁更会回答”，
而是谁能持续完成工作。
01
不要把长文本当独立战略

真正目标是 long-horizon execution：维持目标、处理失败、跨窗口恢复。

02
Coding Agent 是训练场，不只是垂直应用

它首先提供了环境、工具、自动 verifier 和明确经济价值。

03
Post-training 重心转向 trajectory

核心问题从“多少 SFT 数据”变为“什么环境、什么奖励、如何验证结果”。

04
模型、Harness 与产品必须联合设计

前沿 Agent 性能越来越无法仅靠升级 checkpoint 获得。

05
最值得下注的是 Domain Agentic Foundation

领域环境 + 真实轨迹 + verifier + benchmark + agentic training。

技术战略：从“训练一个模型”升级为“建设一个可自我进化的任务系统”
09 · Implication for Social Science

对 Social Science 的启发：不要做“角色扮演 Agent”，要做可验证的社会环境

容易跟风的方向

给多个 Agent 设定人设，让它们讨论、投票、模拟社会，然后把“涌现”当成结论。

真正有价值的方向

让模型面对真实社会状态、干预与反馈，学习行为响应、机制变化和制度边界。

最核心的数据链

社会状态
主体行为
真实干预
响应反馈
机制更新
Social World Model = Environment + Intervention Data + Behavioral Response + Mechanism Verifier
社会科学的独特机会，不是复制 Coding Agent，而是提供 反身性、异质性、制度约束与真实干预。
① 任务定义

预测、反事实、政策评估、机制恢复、群体响应和长期演化。

② 数据资产

互联网回溯数据之外，重点建设“干预—真实响应”的前瞻性数据。

③ 环境建设

政策沙盒、社会模拟器、真实平台实验、人类参与的动态环境。

④ Reward / Verifier

预测误差、干预效果、机制一致性、稳健性、可解释性与审计约束。

⑤ 模型训练

SFT warm-start + outcome-grounded RL + long-horizon interaction training。

⑥ 产品闭环

教育、治理、金融和公共沟通都可成为真实干预与反馈入口。

我们的差异化：不是更像人地说话，而是更可靠地理解、推演和验证社会机制
